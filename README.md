# LifeOS

Personal operating system.

## Current build

LifeOS 0.6 — adaptive planning, calendar execution, habits, money, knowledge, targets, and feedback learning.

## Architecture

- Frontend: static app on Vercel
- Source: GitHub
- Backend: Supabase
- Capture/planning: ChatGPT
- Execution: Google Calendar

## Deploy

Import this repository into Vercel with root directory `/`. No build command is required.
